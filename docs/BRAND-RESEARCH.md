### Как получить файлы в `ByteBot/assets/brand/`

```bash
mkdir -p ByteBot/assets/brand
curl -fsSL https://www.tisbi.ru/bundles/site/tisbi2/img/svgSprite.svg -o ByteBot/assets/brand/tisbi-sprite.svg
curl -fsSL https://www.tisbi.ru/bundles/site/tisbi2/img/safari-pinned-tab.svg -o ByteBot/assets/brand/tisbi-mark.svg
curl -fsSL https://www.tisbi.ru/logo.png -o ByteBot/assets/brand/tisbi-logo.png
curl -fsSL https://www.tisbi.ru/bundles/site/tisbi2/img/logo-vk.png -o ByteBot/assets/brand/tisbi-logo-vk.png
# вытащить отдельные символы в самостоятельные SVG
python3 - <<'PY'
import re, pathlib
src = pathlib.Path("ByteBot/assets/brand/tisbi-sprite.svg").read_text()
out = pathlib.Path("ByteBot/assets/brand")
for sid in ("logo_two-tone", "logo_solid", "logo_solid_pc", "logo-short"):
    m = re.search(rf'<symbol id="{sid}" viewBox="([^"]+)">(.*?)</symbol>', src, re.S)
    if not m: raise SystemExit(f"missing {sid}")
    out.joinpath(f"{sid}.svg").write_text(
        f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="{m.group(1)}">{m.group(2)}</svg>')
PY
```

Оговорка: файлы не сохранены мной — сессия только на чтение. Команды выше проверяемы: обе SVG-ссылки отдают 200, `logo.png` отдаёт `image/png`.

## 7. Что бренд вокруг Байта должен наследовать

1. **Синий — поле, не акцент.** Официальный синий `#0477D2`; `#444B54` — цвет чернил. Оранжевый клюв Байта остаётся единственной тёплой вспышкой (в `STYLE.md` это уже правило). Привести `#0237BB` из `STYLE.md` к официальному `#0477D2` либо явно объявить его «глубоким синим» тенью с пометкой, что это не фирменный цвет вуза.
2. **Типографика: контраст 800/400.** Заголовок — жирный геометрический гротеск (Gilroy-класс или системный аналог), тело — humanist sans (Open Sans-класс). Не брать сам Gilroy без лицензии.
3. **Тон: тёплая официальность.** Студенту — «ты», но без панибратства; факт, потом эмоция; никакого канцелярита в интерфейсе бота. В служебных текстах (правила, дисклеймеры) — регистр `/sveden`: сухо и точно.
4. **Три идеи как контентные столпы.** Образование, инновации, взаимоуважение — официальная формула мерча. Готовые оси для рубрик бота и для текстов о безопасности (уважение к другому = антитеррор/антитравля без лозунгов).
5. **Доступность как часть личности.** Крупный кегль, высокий контраст, текст без цвета-единственного-носителя смысла, простые формулировки. Вуз реально этим занимается — бот обязан соответствовать, а не имитировать.
6. **Казань — фон, не костюм.** Локальность подавать через место (Муштари, центр Казани, Татарстан), а не через орнамент на каждом экране.
7. **Не присваивать Енотиса.** Байт — маскот ByteBot (киви-птица), Енотис — талисман университета. Смешение двух маскотов ломает и вуз, и продукт: Байт не должен изображать Енотиса, спорить с ним или занимать его роль на официальных материалах.
8. **Никаких выдуманных цифр.** Официальные числа противоречивы (30 000 vs 27 000 выпускников; 85 % vs 86 % vs «более 80 %»). В боте либо конкретный источник рядом с цифрой, либо без цифры.
