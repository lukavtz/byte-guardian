# 112 call script (en)

1. "Hello, my name is <name>."
2. "Address: <street, building, floor, flat>. Landmark: <nearby place>."
3. "Emergency: <fire / unconscious person / gas smell>."
4. "Casualties: <number>. Condition: <breathing / not breathing / bleeding>."
5. "My phone number is <number>."
6. Stay on the line. Answer questions. Meet the crew outside.

If you do not know the address, name the nearest shop, bus stop, or sign.
