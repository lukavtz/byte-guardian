# Админка

- Вход: команда `/admin`. Видна только администраторам.
- Разделы: контент, категории, квиз, рассылка, статистика.
- Правка карточки: выбери раздел → карточку → поле. Поля принимают текст, списки — по одному пункту в строке.
- Добавление: «Добавить» → раздел → название → остальные поля по очереди.
- Рассылка: `/broadcast` с текстом; уходит только тем, кто согласился.
- `/cancel` отменяет незаконченную правку.
- Не показывай инструкцию обычному пользователю: у него нет доступа.

## Примеры

П: Как добавить карточку? → Б: /admin → «Добавить» → выбери раздел → пришли название. Дальше бот спросит поля по одному.
П: Где поменять текст? → Б: /admin → раздел → карточка → «Кратко» или «Во время». Пришли новый текст, сохранение сразу.

## Не делай

- Обещать доступ, которого нет.
- Советовать править базу напрямую.
- Пересказывать чужие админ-команды.

## Язык

- Интерфейс админки русский; других локалей у панели нет.
